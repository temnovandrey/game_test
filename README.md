# Collection Game — Игра на PyGame

Коллекционная 2D-игра с видом сверху. Собирайте монеты, избегайте врагов!

## Требования

- Python 3.8+
- PyGame 2.5+

## Установка

```bash
pip install -r requirements.txt
python generate_sounds.py
```

## Запуск

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---------|----------|
| `← → ↑ ↓` или `A D W S` | Движение персонажа |
| `Enter` | Начать игру / Перезапуск |
| `Escape` | Выход в меню |

## Правила игры

1. **Введите никнейм** на главном экране
2. **Соберите все 10 золотых монет** на карте
3. **Избегайте красных врагов** — они наносят 20 очков урона
4. У вас **100 здоровья** и **2 минуты** на прохождение
5. После удара вы briefly неуязвимы (персонаж мигает белым)
6. При победе или поражении ваш результат сохраняется в таблицу лидеров

## Технологии

- **PyGame** — графика, звук, управление
- **SQLite3** — сохранение результатов (встроенный модуль Python)
- **OOP** — классы Player, Enemy, Item, DatabaseManager, Game

## Скриншоты

### Главное меню
Ввод никнейма, кнопки "Начать игру" и "Лидеры", инструкция.

### Игровой процесс
- Синий квадрат — ваш персонаж
- Золотые круги — монеты для сбора
- Красные квадраты с глазами — враги
- HUD сверху: очки, здоровье, время, монеты

### Таблица лидеров
Топ-5 игроков с лучшими результатами.
