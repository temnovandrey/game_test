# Implementation Plan: PyGame Collection Game

## Summary
Build a PyGame collection game from scratch with OOP architecture. The player collects items (coins) while avoiding enemies on a 2D map. The game features a main menu, gameplay loop, win/lose screens, and a SQLite3 leaderboard. All assets (graphics, sound) use simple shapes and programmatically generated audio.

## File Structure
```
инжинириум/
├── main.py              # Entry point, state machine, game loop
├── game/
│   ├── __init__.py
│   ├── player.py        # Player class
│   ├── enemy.py         # Enemy class
│   ├── item.py          # Collectible item class
│   ├── game.py          # Game logic class
│   └── database.py      # DatabaseManager class (SQLite3)
├── assets/
│   ├── sounds/          # Sound effects (.wav)
│   └── music/           # Background music (.wav)
├── generate_sounds.py   # Utility to generate sound files
└── requirements.txt
```

## Step 1: Setup Project Structure
- Create directories: `game/`, `assets/sounds/`, `assets/music/`
- Create `game/__init__.py`
- Add `pygame>=2.5.0` to `requirements.txt`
- Run `pip install -r requirements.txt`

## Step 2: Database Module (`game/database.py`)
**Schema:**
```sql
CREATE TABLE IF NOT EXISTS leaderboard (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    player_name TEXT NOT NULL,
    score INTEGER NOT NULL,
    game_date TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

**Class `DatabaseManager`:**
- `__init__(db_path)` — connects to SQLite, calls `init_db()`
- `init_db()` — creates leaderboard table
- `insert_score(player_name, score)` — inserts a new entry
- `get_top_5()` — returns top 5 players by score DESC
- `close()` — closes connection

## Step 3: Player Class (`game/player.py`)
- Blue rectangle (40x40), starts at (100, 100)
- Movement: arrow keys + WASD, speed=5 px/frame
- Health: 100 HP, takes 20 damage per enemy hit
- Score: +10 per coin collected
- Invincibility timer: 0.3s flashing after being hit
- Methods: `move()`, `draw()`, `take_damage()`, `add_score()`, `get_rect()`, `is_alive()`, `reset()`

## Step 4: Enemy Class (`game/enemy.py`)
- Red rectangle (35x35), spawns away from player start
- AI: moves in straight line, bounces off walls, random direction changes every 1-2 seconds
- Methods: `move()`, `draw()`, `get_rect()`, `reset()`

## Step 5: Item Class (`game/item.py`)
- Gold circle (radius 12), spawns randomly (not near player start)
- 10 items total at game start
- Methods: `draw()`, `get_rect()`, `collect()`, `is_collected()`, `reset()`

## Step 6: Game Logic (`game/game.py`)
- **Win condition**: Collect all 10 coins
- **Lose condition**: Health <= 0 OR time runs out (120 seconds)
- **HUD**: Score, Health bar, Timer, Items collected/total
- **Collision detection**: `pygame.Rect.colliderect()`
- **Sound effects**: coin collect, hit, win, lose + background music
- Methods: `init_game()`, `handle_events()`, `update()`, `draw()`, `check_collisions()`, `spawn_enemies()`, `spawn_items()`

## Step 7: Sound Generation (`generate_sounds.py`)
Generate WAV files programmatically using `wave` and `struct` modules:
- `coin.wav` — 800 Hz ding (0.15s)
- `hit.wav` — 150 Hz thud (0.3s)
- `win.wav` — ascending arpeggio C5-E5-G5-C6 (0.5s)
- `lose.wav` — descending C5-A4-F4-C4 (0.5s)
- `background.wav` — low ambient loop (5s)

## Step 8: Main Entry Point (`main.py`)
**Game States (Enum):**
- `MENU` — enter name, start game, view leaderboard
- `PLAYING` — active gameplay
- `GAME_OVER` — win/lose screen with score
- `LEADERBOARD` — top 5 players table

**Screen Flow:**
```
MENU → PLAYING → GAME_OVER (win/lose) → MENU / RESTART / LEADERBOARD
MENU → LEADERBOARD → MENU
```

**Menu Screen:**
- Title: "Collection Game"
- Text input for player name (alphanumeric, max 20 chars)
- Buttons: "Start Game", "Leaderboard"
- Instructions: movement, goal, enemies, time limit

**Game Over Screen:**
- "YOU WIN!" (green) or "GAME OVER" (red)
- Final score and name
- Buttons: "Restart", "Leaderboard", "Main Menu"

**Leaderboard Screen:**
- Table: # | Name | Score | Date
- Back button

## Step 9: Verification

3. Run `python main.py` — launch game
4. Test full flow: enter name → play → win/lose → view leaderboard → restart
